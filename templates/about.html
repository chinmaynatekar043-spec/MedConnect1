ABOUT THE PROJECT

MedConnect

A Python + DBMS + Data Structures patient care finder.

Problem Statement

Patients often do not know whom to contact for a health problem. This project provides one dashboard where a patient can enter a problem and get nearby medical contacts, doctors or hospitals based on seriousness, specialty and distance.

Python

Flask handles routes and pages. Python also performs severity routing, keyword matching, Haversine distance calculations and provider scoring.

DBMS

SQLite stores providers, demo conditions and search history. SQL is used for filtering, grouping, counting and analytics.

Data Structures

Lists and dictionaries store and transform result data, sets are used for token matching, and a heap is used for efficient top-k provider ranking.

Medical safety: MedConnect is an academic directory prototype. It does not diagnose, prescribe medicine, or replace a licensed healthcare professional.
